#PASOS A SEGUIR PARA EMPEZAR A TOMAR APUNTES DE UNA CLASE NUEVA#

1) Copiar el Library y pegar
2) Cambiarle nombre (ej: claseN)
3) Modificar el "module Library where" por "module claseN where"
4) Para poder hacer los test agregar "import claseN (nombre_funciones...)"

Con todo esto ya podrias codear sin problema.
